# 微信任务栏改名 · WeChatTabName

给多开微信的窗口起名字，任务栏上直接显示「工作」「私人」，不用再靠猜。

单文件 24 KB，免安装，不联网，不需要管理员权限，不注入微信进程。

- 版本：1.0.0
- 适用：Windows 10 / 11（32/64 位均可）
- 实测：微信 4.2.0.53（`Weixin.exe`），同时兼容 3.x（`WeChat.exe`）
- 文件大小：24,064 字节
- SHA-256：`4FA1A68DF1994BF3FEF0DD88FD67AAA056A4BC26C64CE585FC26364AB70CC1E4`

> **下载**：本仓库 Releases 里的 `WeChatTabName-1.0.0.zip`（exe + 说明 + 源码）
> **源码**：`src/`，编译方法见下面「构建」一节

---

## 一、它解决什么问题

Windows 11 任务栏默认「合并按钮 + 隐藏标签」，多开两个微信时只剩两个一模一样的绿色图标，分不清哪个是工作号、哪个是私人号。

本工具按**账号身份**（微信数据目录里的 `wxid_xxx`）给窗口标题命名：

- 一旦命名，重启微信、调换登录顺序、窗口挪位置都不影响；
- 任务栏标签（配合 Windhawk 的 `Taskbar Labels for Windows 11`，或系统「任务栏行为 → 从不合并」）会直接显示你起的名字。

## 工作原理

多开时两个微信进程的命令行完全一样（都是裸的 `Weixin.exe`），窗口标题也都写成「微信」，靠名字区分不开。所以本工具的身份标识用的是**账号数据目录名**：

1. 微信运行时会在 `...\xwechat_files\wxid_xxx\db_storage\` 下持续占用若干 SQLite 文件；
2. 工具调用 Windows 的 **Restart Manager**（`rstrtmgr.dll`，就是弹「文件被占用，请关闭程序」那套 API），查 `session.db` 正被哪个 PID 打开；
3. 于是得到 `PID → wxid`，再取该 PID 的主窗口句柄；
4. 名字存在 `config.ini` 的 `wxid_xxx=名字` 里，2 秒一轮把标题刷成配置值。

键是 wxid，所以重启微信、换登录顺序、窗口挪位置都不影响结果。

关键代码：`src/WeChatTabName.cs` 中的 `RM.WhoUses` / `WeChat.BuildPidMap` / `TrayApp.Apply`。

已知边界：只改主窗口；若某天微信不再占用那些 db 文件，识别会失效，届时退回“按窗口顺序编号”兜底。

## 四、安装与使用

### 1. 放置

把 `WeChatTabName.exe` 放到一个**固定目录**，例如 `D:\Tools\WeChatTabName\`。
不要放在「下载」文件夹里，也不要每次从压缩包里直接双击运行。

### 2. 启动

双击运行。托盘出现一个绿色对话气泡图标，没有主窗口。

### 3. 开机自启（推荐）

托盘图标右键 → 勾选「开机自动启动」。
（实现方式：写一条 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不勾就不写。）

### 4. 首次命名

1. 打开第一个微信窗口，确认它在最前面；
2. 按 `Ctrl+Alt+R`，输入名字（例如「工作」），回车；
3. 对第二个微信窗口重复一次，起名「私人」。

之后这两个名字会和对应账号永久绑定。

### 5. 改名

随时切到那个微信窗口，按 `Ctrl+Alt+R` 重新输入即可，2 秒内生效。

### 6. 配置文件

`%APPDATA%\WeChatTabName\config.ini`，纯文本：

```ini
# WeChatTabName config
DataRoot=D:\WeChatData\xwechat_files
wxid_xxxxxxxxxxxxxxxx_abcd=工作
wxid_yyyyyyyyyyyyyyyy_ef01=私人
```

- 一行一个 `DataRoot`，可以写多个微信数据目录；
- 一行一个 `wxid_xxx=名字`；
- 直接用记事本改、保存，工具 2 秒内会读到并应用；
- 托盘菜单「打开配置文件」可以直接打开它。

## 五、卸载

1. 托盘右键 →「退出」；
2. 删除 `WeChatTabName.exe`；
3. 删除 `%APPDATA%\WeChatTabName\` 文件夹；
4. 如果开过机自启：托盘菜单里取消勾选，或删掉注册表项
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WeChatTabName`。

卸载后微信窗口标题会在下次启动时恢复成默认的「微信」，没有任何残留改动。

## 六、安全声明

### 它只做四件事

1. 读自己的配置文件；
2. 按名字找 `Weixin.exe` / `WeChat.exe` 进程，取其主窗口句柄；
3. 用 Windows 官方 **Restart Manager API**（就是「文件被占用，请关闭程序」用的那个接口）查询某个数据库文件被哪个进程打开，从而得到 `wxid`；
4. 调用 `SetWindowText` 修改那个窗口的**标题文字**。

### 它明确不做的事

- 不联网：没有 HTTP / socket / DNS，断网功能完全正常；
- 不注入：不往微信进程里写代码、不 Hook、不读微信内存；
- 不改文件：不读取、不解密、不修改聊天记录和数据库内容，只是"问系统：这个文件被谁打开着"；
- 不上传：没有任何数据外发；
- 不装驱动、不装服务、不开后门、不写系统目录；
- 不改系统设置：只有你主动勾选「开机自动启动」时，才写一条当前用户的 Run 键。

### 数据落在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 账号名映射 | `%APPDATA%\WeChatTabName\config.ini` | 纯文本，只有 wxid 和名字，可随时查看/删除 |
| 开机自启项 | `HKCU\...\CurrentVersion\Run` | 仅勾选后存在，可随时删除 |

除此之外**不产生任何文件**。

## 七、为什么会被杀毒软件误报

这是**未签名的国产小工具几乎必然遇到的**，不是本工具独有：

1. **没有数字签名 + 文件很新 + 用的人少** → 360/火绒/Defender 的云端信誉分低，直接按"未知程序"拦；
2. **行为特征敏感**：跨进程修改窗口标题、注册全局热键、枚举进程、访问其他程序的目录——这几个动作组合起来和某些外挂行为相似；
3. **编译产物是全新的 PE 文件**，没有历史白名单记录。

本工具**没有加壳、没有混淆**（加壳反而更容易被判为可疑）。如果你的杀软报毒，按下面处理。

### 加白名单步骤

2. 找到被拦的记录 →「操作」→「允许在设备上」；
3. 或：「病毒和威胁防护」→「管理设置」→「排除项」→「添加排除项」→ 选择该 exe 或所在文件夹。

**火绒**

1. 主界面 → 右上角菜单 →「信任区」→「添加文件」，选中 `WeChatTabName.exe`；

**360 安全卫士 / 360 杀毒**

2. 或：「木马查杀」→「恢复区」→ 找到文件 →「恢复并信任」；
3. 或：「设置」→「白名单」→「添加文件/目录」。

**SmartScreen（下载后首次运行被拦）**

1. 右键 exe →「属性」→ 底部勾选「解除锁定」→ 确定；
2. 或运行时点「更多信息」→「仍要运行」。

## 九、常见问题

**Q：按 Ctrl+Alt+R 没反应？**
A：① 前台不是微信窗口（先点一下微信窗口再按）；② 热键被别的软件占用（启动时托盘会提示，改用托盘菜单改名）；③ 被杀软拦了。

**Q：提示「查不到这个窗口对应的账号目录」？**
A：微信数据目录不在默认位置。托盘右键 →「选择微信数据目录…」，选到包含 `wxid_xxx` 文件夹的那一层（例如 `C:\Users\你的用户名\xwechat_files`）。

**Q：名字设好了，过两秒又变回「微信」？**
A：还有别的改名工具在跑（比如 AutoHotkey 脚本），两个程序在互相覆盖。只保留一个。

**Q：标题改好了，但任务栏上还是只看到图标？**
A：那是任务栏没开标签，跟本工具无关。二选一：
- 装 Windhawk 的 `Taskbar Labels for Windows 11`，模式选 `labelsWithoutCombining`；
- 或系统设置 → 个性化 → 任务栏 → 任务栏行为 →「合并任务栏按钮并隐藏标签」→「从不」。

**Q：微信升级后失效了？**
A：微信可能改了数据库路径。工具会在这个账号目录下逐个尝试 `*.db`；都不行时用托盘菜单重选一次数据目录。仍不行请反馈。

**Q：微信是以管理员身份运行的吗？**
A：普通启动即可。若你的微信确实用管理员运行，本工具也要右键「以管理员身份运行」，否则改不动它的窗口标题。

**Q：支持三个及以上账号吗？**
A：支持，每个账号按一次 `Ctrl+Alt+R` 起名即可，没有数量限制。

## 十、已知限制

- 只改**主窗口**标题；单独拖出来的聊天窗口（标题是联系人名）不会被动。
- 依赖微信数据目录里的 `db_storage\*.db` 文件被占用来识别账号；若某天微信不再占用这些文件，识别会失效（工具会保留"按顺序"兜底逻辑）。
- 需要常驻托盘（约 15 MB 内存、CPU 基本为 0）。
